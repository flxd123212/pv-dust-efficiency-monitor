# 扩展板传感器核查与修复

## 结论

旧版不是随机生成模拟数值，但存在严重的采集映射和换算错误，不能把其显示值当作真实温度、光伏电流或雨滴测量。
本机检查时服务为真实串口模式（simulation=false），COM6 收到了设备上报；这只证明数据来自设备，不证明物理量解释正确。

| 原显示 | 实际硬件 | 原问题 | 修复后 |
|---|---|---|---|
| 板温 | PB1/ADC1_IN9，扩展板 ANA1，R66 电位器经 U12B 电压跟随器输出 | `adc * 120 / 4095` 把电压当温度；ADC=3072 时显示约 90℃ | PB1 仅保留为电压通道原始诊断，不参与温度计算 |
| 温度 | U11 SHT20/Si7006，I2C 地址 0x40，PB6 SCL / PB7 SDA | 原固件未读取这个传感器 | 发送 0xF3 非保持测量，等待转换后读取 3 字节、检查应答和 CRC，按 SHT20 公式换算 |
| 电流 | PB0/ADC1_IN8，ANA0；R54=0.1Ω，U12A 放大倍数 101 | 原系数约 330mA/V，比图纸对应的 99.01mA/V 约大 3.33 倍 | `I_mA = ADC * 33000 / (4095 * 101)`，满量程约 326.7mA |
| 雨滴 | 扩展板没有雨滴传感器；底板 PA1 是五向按键 KEY-A 的运放输出 | 原固件直接把 PA1 高低电平解释为晴雨 | 不再触碰 PA1；按用户外接模块启用 PA4/DO，低电平保护，高电平稳定 500ms 后无雨 |
| 积灰 | 没有直接测量灰尘的传感器 | 由电流相对基准计算，光照和负载变化同样影响结果 | 仅在有效电流、完成标定且电流足够时发布估计值；其他情况为 null |
| 人体红外 | U10/RDA226，REL 经 J1/J6 引脚 16 到 PB4 | 原固件未读取 | PB4 高电平活动报警，60 秒预热，持续低 5 秒后清除；预热/失效为未知，不伪造无人 |
| 热敏 | 用户四针NTC模块，AO接PA5，实际B值待确认 | 原照片DO接线、AO悬空；ADC129为比较器低电平 | 改接AO后1940→1665响应；按可配置10k/B3950模型给出20～80℃估算，独立显示，不冒充校准测温 |

## 为什么拔掉扩展板还有数字

STM32 ADC 在模拟输入悬空时仍会完成转换，受浮空电压、漏电、邻近通道与采样保持电容残留影响，会得到非零且变化的数字。
原逻辑只检查转换是否超时，因此错误地把浮空读数认定为有效传感器测量。滤波不能解决接线缺失或映射错误。

修复版要求读到真实 SHT20 应答及有效 CRC，才把该扩展板的模拟电流通道认定为可用；失败、超时、过期、ADC 饱和时不发布有效电流。
这是一种基于已知整板连接的有效性门控，不是逐根模拟线的通断检测：如果 SHT20 仍在线而单独拔掉 PB0，软件无法仅靠一个 ADC 数值百分之百证明断线。
原始 ADC 诊断值可以仍存在，但与有效测量分开；不能把这些原始值再当作温度或发电量。

## 数据和保护边界

- SHT20 测的是所在位置的环境温度，不是未贴合测量的光伏板表面温度；网页改名“环境温度”，LCD 显示 SHT20。
- API 的 `panelTemp` 保留旧字段名以兼容现有页面，但 protocol=3 时语义明确为 SHT20 环境温度，不是热敏电阻板温。
- 是否确实测到光伏发电电流，还取决于采样电阻是否串入真实光伏电流回路、图纸与实物是否一致，以及 3.3V 参考和零点校准；未确认前显示“采样电流”。
- 原扩展板没有雨滴传感器；现按用户确认的外接四针模块接入 PA4，代码开关为 `PV_RAIN_PA4_ENABLED=1`。
  VCC 接 3.3V（模块需支持 3.3V），GND 共地，DO 接 PA4，AO 不接；不连接 PA1，不输入 5V 电平。
- PA4 内部下拉。低电平按有雨保护，高电平连续稳定 500ms 才判无雨；未就绪或采样过期返回未知。
  在 DO 线悬空且下拉有效时会按有雨处理，不能区分下雨与断线，也不能保证识别模块断电、输出短路等所有故障。
  因此 rain=100 是低电平保护状态，可能为有雨或断线，不能据此声称已独立确认实际天气。
  如果没有外接模块，可以将上述开关设为 0，保持雨滴未知和清扫锁定；不要为演示伪造无雨。
- 参数存储版本升为 3，旧版错误电流比例对应的基准不再加载，需要重新标定并保存；上电仍为手动、停止清扫。
- protocol=2 的历史原记录保留，展示/CSV 屏蔽其无依据的温度、电流、积灰和雨滴值，并标记 legacy；不会伪造一条“修正后的历史测量”。

## 实机验收

1. 插拔扩展板先断电，确认排线方向，烧录新 HEX 后复位。
2. 不接扩展板开机：设备可在线，但环境温度、电流、积灰应显示 `--`，温度状态为 missing/timeout，不得显示室温默认值。
3. 接好扩展板开机：SHT20 有应答和 CRC 后显示实测环境温度；PB1 电位器旋转只改变 ADC I/V 的第二项，不应再把环境温度调到 90℃。
4. 与独立温度参考比较。无需为本项目添加硬件，但未比较前不要声称达到某个测量精度。
5. 电流只有在真实回路与采样路径核实后才标定；无实际负载时若有明显电流，检查零点、放大器偏移、地线和接线，不能直接当作光伏发电。
6. 雨滴模块按上述三根线连接，调电位器阈值。干燥时 DO 应为高电平、持续 500ms 后显示 DRY/rain=0；
   滴水时 DO 应为低电平，下一次 250ms 采样应进入 RAIN/rain=100，并拒绝清扫启动/停止正在进行的清扫。
   当前联动固件还会退出自动清扫、平滑转向 90° 挡雨；连续无雨 10 秒后收至 0°，不恢复清扫。
   实测前清空舵机运动范围，按停止应保持当时角度，必须点“恢复联动”或 LCD RESUME 才继续。
   先断电拔 DO，再开机，应保持 RAIN 保护而不是无雨；不要带电插拔作短路风险测试。
   此次没有实物可做上述验证，不能声称雨滴模块已完成实机验收。

主机测试覆盖实际 SHT20 驱动的无应答、CRC 错误、超时、恢复、过期、负温与时钟回绕；
PA4 雨滴驱动覆盖实际初始化引脚/下拉、低电平保护、500ms 干燥去抖、过期及回绕；
业务测试覆盖拔板后停止清扫、无效值为 null、雨滴未知时拒绝启动；浏览器测试区分“设备在线但传感器掉线”和“设备离线”。
雨天联动业务测试还覆盖 0/90°、10 秒边界、再下雨、过期/缺失重计时、STOP/恢复及计时回绕。
这些是软件与模拟链路验证，不代替实物行程、供电和模块湿干阈值的验收。
